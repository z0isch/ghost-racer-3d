# World-space name labels over the entry lines

Status: closed
Blocked by: 08

A billboarded world-space label carrying the track's `display_name`, standing over each circuit's
entry line in the open world.

World-space rather than a HUD prompt that appears within N metres: the information is useful while
you are deciding where to drive, which is well before you are close enough for a proximity prompt to
fire, and it scales to more circuits without cluttering the HUD.

Reuse the billboarding in `scripts/pickup_popups.gd` if it fits.

Done when: both circuits are named from across the world.
